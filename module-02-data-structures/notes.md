# 🧠 Module 02: Data Structures in R

## 1. Vectors

- Homogeneous (same type)
- Use `c()` to combine values

## 2. Matrices

- 2D arrays with one data type
- Created with `matrix()`, modified with `dimnames()`

## 3. Lists

- Heterogeneous elements
- Use `list()` and access with `$` or `[[ ]]`

## 4. Factors

- Used for categorical variables
- Use `factor()`, get levels with `levels()`

## 5. Data Frames

- Most used structure for datasets
- Like a table: each column can be a different type
