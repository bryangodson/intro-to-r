# 📘 Module 01: R Basics — Notes

## Variables

Use `<-` or `=` for assignment. Prefer `<-` in scripts for consistency with R style.

## Data Types:

- Numeric: 1, 3.14
- Character: "hello"
- Logical: TRUE, FALSE
- Vector: c(1, 2, 3)

## Operators:

- Arithmetic: `+`, `-`, `*`, `/`, `%%`, `^`
- Comparison: `==`, `!=`, `>`, `<`, `>=`, `<=`
- Logical: `&`, `|`, `!`

## Functions to Remember:

- `length()`, `sum()`, `mean()`
- `class()`, `typeof()`
- `help()`, `args()`, `?`

## Print:

- `print()` for general output
- `cat()` for formatted output
