# 📘 Module 03: dplyr Basics

## select()

Pick columns you need.

## filter()

Filter rows by condition(s).

## arrange()

Sort rows ascending or descending.

## mutate()

Add new columns or modify existing ones.

## group_by() + summarise()

Group your data and then summarize/aggregate it.

## Pipe operator %>%

Chains multiple operations in a readable format.
